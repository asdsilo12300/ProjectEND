# Font Awesome Configuration

## Integration

- **Method:** React SVG components with a hosted Kit available for Kit/custom icons
- **Kit ID:** `f83817c91c`
- **Framework:** React with Vite
- **Renderer:** `@fortawesome/react-fontawesome`

## Defaults

- **Style:** Solid
- **Family:** Classic
- **Application wrapper:** `AppIcon`

## Import Pattern

Import `AppIcon` from `src/game/icons/FontAwesomeIcon.jsx`. Components use semantic application names such as `plant`, `shop`, and `notifications`; the central map translates them to individually imported Font Awesome icon definitions.

## Conventions

- Add new icons to the central `iconMap` instead of adding Font Awesome class names throughout the application.
- Prefer Free solid icons unless the Kit is confirmed to include a Pro style.
- Decorative icons remain hidden from assistive technology. Pass `label` when an icon communicates meaning without adjacent text.
- Keep Kit icon selection set to Free Full Library while developing, or include every icon referenced by `iconMap` when using By Icon mode.
