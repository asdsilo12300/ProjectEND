# React frontend — Plant Growth Academy

วิธีติดตั้ง Node.js, ตั้ง `frontend/.env`, เปิด Vite และเชื่อมกับ Laravel API อยู่ใน [README หลัก](../README.md) โดยเฉพาะขั้นตอนที่ 6

หลังติดตั้ง dependencies ด้วย `npm ci` ใช้ `npm run dev` เพื่อพัฒนา, `npm run lint` เพื่อตรวจโค้ด และ `npm run build` เพื่อตรวจการสร้างไฟล์ก่อน Deploy
